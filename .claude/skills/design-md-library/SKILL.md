# Design.md Library

A curated collection of `DESIGN.md` files — plain-text design-system documents (a format AI agents read to generate consistent UI) extracted from real, high-quality websites. Source: https://github.com/VoltAgent/awesome-design-md

## When to Apply

Use this Skill when a UI/styling task references a specific brand aesthetic, e.g. "make it look like Stripe", "use Linear's design language", "Apple-style landing page", or when the user wants polished, consistent visual output anchored to a known design system.

## How to Use

1. Identify the target brand (or the closest match) from the list below.
2. Read `references/<brand>/DESIGN.md` — it contains the design tokens, color system, typography, spacing, component patterns, and visual rules for that brand.
3. Apply those tokens and rules when generating or reviewing UI. Stay faithful to the documented values rather than improvising.
4. If no specific brand is requested, suggest 2-3 brands whose style fits the project and let the user pick.

Pair this with the `ui-ux-pro-max` and `ui-styling` skills for stack-specific implementation (Tailwind, shadcn/ui, React, etc.).
